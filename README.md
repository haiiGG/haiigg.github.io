# Portafolio - Haiat Ghaddari

Mi página web personal, hecha con HTML, CSS y JavaScript.

Estudiante de CFGS en Desarrollo de Aplicaciones Multiplataforma.

## Archivos

```
portafolio/
├── index.html          → la estructura de la página
├── css/
│   └── estilos.css     → los estilos
├── js/
│   └── main.js         → el JavaScript
├── img/                → las imágenes
└── docs/
    └── Cv_HaiatGhaddari.pdf
```

## Qué tiene

- Una intro con el dibujo de un bosque que se acerca al hacer scroll
- Modo claro y modo oscuro
- Mis datos personales, habilidades, experiencia, proyectos,
  formación y contacto
- Se adapta al móvil

## Cómo verlo

Abrir el archivo `index.html` con el navegador.

## Cómo añadir cosas

Todo el contenido está escrito directamente en `index.html`.

Para añadir un proyecto nuevo, copiar un bloque `<div class="tarjeta">`
de la sección de proyectos y cambiar el texto.

Para añadir un certificado, lo mismo en la sección de formación.

Los colores están al principio de `css/estilos.css`, en las variables.
